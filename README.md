# sama-3atef.github.io
Static portfolio for Sama Atef Elesily (HTML + CSS + vanilla JS, no build step).

## Assets
Photos live in `assets/images/`. Club logos load from Wikimedia; offline copies can go in `assets/logos/` (`al-ahly.svg`, `real-madrid.svg`) as a fallback.

## Deploy to GitHub Pages
1. Create a public repo named exactly `sama-3tef.github.io` under the `sama-3tef` account.
2. Run:
```
git init
git add .
git commit -m "Launch portfolio"
git branch -M main
git remote add origin https://github.com/sama-3tef/sama-3tef.github.io.git
git push -u origin main
```
3. Repo Settings → Pages → Source: `main` / root. The site appears at https://sama-3tef.github.io/ after a minute or two.
